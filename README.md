# FT-IR Studio v1.6

**FT-IR 탭** — Bruker OPUS 스펙트럼(원시 바이너리 `.0`/`.1` 또는 ASCII `.dpt`)을 **설치 없이** 열어서 스택 비교·정성 판정·열화 지수 계산·차이 스펙트럼까지 처리합니다.
**DSC 탭 (v1.3 추가)** — DSC ASCII 데이터(`온도 / 열유량`)를 읽어 피크 적분(ΔH)·외삽 onset/endset·Tg·ΔCp·결정화도를 계산합니다.
**TGA 탭 (v1.4 추가)** — TGA ASCII(`온도 / 중량`)를 읽어 T5%·T10%·T50%, 외삽 분해개시온도(Td,onset), DTG 최대점(Tmax), 잔량, 중량 감소 단계를 계산합니다.
**우측 요약 패널 (v1.4)** — DSC·TGA 모두 메인 곡선 오른쪽에 **주요 지점만 따로 그린 작은 그래프**가 붙습니다(전이온도·ΔH / T5%·Td·잔량). 슬라이드·도판용 한 장짜리 그림이 바로 나옵니다.
**그림 내보내기** — 학술지용(double 180 mm, 300 dpi, 7 pt)과 PPT용(16:9, 투명 배경) 두 형식으로 바로 저장합니다.
의존성 없음(순수 HTML/CSS/JS), 인터넷·파이썬·엑셀 불필요. 데이터는 PC 밖으로 나가지 않습니다.

## 1. 실행

- **`FTIR-Studio 실행.bat` 더블클릭** → Edge/Chrome 앱 모드(주소창 없는 창)로 열립니다.
- 또는 `ftir-studio.html` 더블클릭 (일반 브라우저 탭).
- USB·메일로 옮길 때는 **`ftir-studio-single.html`** 하나만 복사하면 됩니다(모든 코드가 한 파일에 인라인된 배포본).

## 2. 데이터 불러오기

### 2-1. OPUS 원시 바이너리 — 변환 없이 그대로 (v1.1 추가)

`.0`, `.1`, `.2` … 파일을 **그대로 끌어다 놓으면** 읽습니다. OPUS에서 ASCII로 내보낼 필요가 없습니다.

동작 방식
- 파일 안에는 인터페로그램·위상·단일채널·흡광도가 함께 들어 있습니다. 이 중 **결과 스펙트럼(흡광도 우선)** 을 자동 선택하고, 무엇을 골랐는지 로그에 표시합니다.
- x축은 `linspace(FXV, LXV, NPT)`, y값은 `저장값 × CSF`로 복원합니다(OPUS 규격 그대로).
- **무결성 검사**: 파일 내부에 기록된 최소·최대값(`MNY`/`MXY`)과 실제 계산값을 대조합니다. 1 % 이상 벗어나면 **불러오지 않고 실패로 기록**합니다 — 값이 조용히 틀어지는 것을 막기 위한 장치입니다.
- 함께 읽어 표시하는 메타데이터: 기기·시리얼, 분해능, 스캔 수, 액세서리, 검출기, 측정일시, 시료명(`SNM`).

지원하지 않는 것
- 3D 시계열(series) 블록, 라이브러리 검색·정량 리포트 블록 (OPUS에서 열어 ASCII로 내보내세요)
- Bruker 이외 제조사 포맷(Thermo `.spc` 등)

포맷 근거: 공개 포맷 문서와 오픈소스 구현(`brukeropus` MIT, `openreadout`)을 대조해 작성했습니다.

### 2-2. ASCII 내보내기 (여전히 지원)

1. OPUS에서 스펙트럼 열기 → **File → Save File As** (또는 **Export → ASCII / .dpt**)
2. 형식: **ASCII / .dpt**, 내용: `wavenumber  absorbance` 2열
3. 여러 개는 한 폴더에 모아 **전부 선택해 창에 끌어다 놓기**

지원 형식: `.0`~`.20`(바이너리) `.dpt .txt .csv .tsv .asc .dat`(ASCII)
ASCII 자동 처리 — 탭/쉼표/공백 구분, 헤더 무시, 3열이면 순번 무시, `%T`면 **흡광도 자동 변환**(`-log10(T/100)`)

## 3. 화면

- **왼쪽**: 시료 목록(순서 변경 ↑↓, 표시/숨김, 삭제) + 선택 시료의 **범례 문구·색·굵기·선형태·투명도**
- **가운데 위**: 그래프. 드래그=구간 확대, 휠=줌, 더블클릭=초기화, 범례 클릭=시료 선택
- **가운데 아래**: 피크 표 / 정성 판정 / 열화 지수 / 라이브러리 / 로그 (경계선 드래그로 높이 조절, 더블클릭으로 접기)

표시 설정: 스택 ↔ 겹쳐보기, 시료별 높이 정규화, X축 역순(4000→400), 격자, 피크 마커/라벨,
글꼴 크기, 범례 표시/위치(**바깥 위·아래·왼쪽·오른쪽** + 안쪽 네 모서리)와 크기, 피크 라벨 표시 기준(prominence).

## 4. 전처리

| 항목 | 내용 |
|---|---|
| 스무딩 | Savitzky–Golay (창 길이·차수 지정) |
| 베이스라인 | 선형(두 점) / 다항식(차수) / **러버밴드** |
| ATR 보정 | 단순형 `A_corr = A · ν/1000` (diamond·ZnSe n=2.40, Ge n=4.0) |
| 정규화 | 최대값 / 0–1 / 벡터 / 특정 밴드 면적 / **특정 밴드 피크 높이**(내부 표준, 예: 1440–1480) |

전처리는 **모든 시료에 동일 적용**됩니다. 시료별로 다르게 하려면 해당 시료만 불러 전처리를 바꿔
프로젝트로 저장하세요.

### 4-1. 특정 밴드 피크 높이 정규화 (내부 표준 방식)

시편 두께·ATR 접촉 압력·충전제 함량이 시료마다 다르면 절대 흡광도는 비교할 수 없습니다.
이때 **조성 변화에 둔감한 기준 밴드의 피크 높이를 1(또는 지정값)로 맞추고** 나머지 밴드를 상대 비교합니다.

쓰는 방법
1. 전처리 → 정규화: **특정 밴드 피크 높이 (내부 표준)** 선택
2. 밴드1/밴드2 에 기준 밴드 범위 입력 (예: PA6 1440–1480, PPS 1080–1100, PE 1460–1480)
3. 기준 피크 높이: 보통 1.0 (100으로 두면 % 스케일)
4. 필요하면 **밴드 양끝 직선을 먼저 제거** 체크 — 밴드 경계 두 점을 잇는 직선을 빼고 얻은 순수 피크 높이를 기준으로 씁니다

동작
- 밴드 안 최대 흡광도를 찾아 `y' = y × (기준값 / 그 높이)` 로 전체 스펙트럼을 스케일합니다 (모양은 유지).
- **밴드 양끝 직선**을 켜면 그 직선은 *높이를 재는 기준*으로만 쓰입니다. 스펙트럼 자체는 스케일만 되므로 모양이 유지되고, 기울어진 베이스라인 위에 앉은 밴드도 순수 높이로 잡힙니다.
- 정규화 후 스펙트럼 = `원본 × (기준값 / 기준 피크 높이)` — 위치·모양·피크 비율은 변하지 않습니다.
- 밴드 안 최대값이 0 이하이면 정규화를 건너뛰고 로그에 경고를 남깁니다(0으로 나누지 않음).
- 로그에 `기준 피크 위치 · 높이 · 기준값`이 찍히므로 그림 캡션에 그대로 쓸 수 있습니다.

주의
- 기준 밴드는 **열화·배합 변화로 강도가 변하지 않는 밴드**를 골라야 합니다. 카르보닐(1700–1750)처럼 변하는 밴드를 기준으로 잡으면 비교가 무의미해집니다.
- 충전제(GF 등)가 기준 밴드를 덮으면 정규화가 흔들립니다. 그럴 땐 1000–1100 cm⁻¹ 밖의 밴드를 고르세요.
- 정규화는 **비율(CI 등)에는 영향이 없습니다** — 분자·분모가 함께 스케일되기 때문입니다. 절대 흡광도 비교·스택 그림에서만 효과가 있습니다.

## 5. 분석 기능

### 5-1. 피크 표
자동 검출(prominence·최소 간격 지정) → 위치/강도/prominence/**귀속 후보**/라벨.
라벨은 표에서 직접 수정하면 그래프에 바로 반영됩니다. CSV 저장 가능.

### 5-2. 정성 판정 (미지시료 성분 특정)
내장 밴드 라이브러리(열가소성·열고무·열경화성 40여 종 + 충전제·첨가제)로 **마커 밴드 점수**를 계산합니다.

- **점수 = 0.65 × 마커 충족률 + 0.35 × 스펙트럼 설명률**
  - 마커 충족률: 필수(w=3)·강(w=2)·보조(w=1) 밴드가 실제 피크로 존재하는 비율
  - 스펙트럼 설명률: 이 후보의 밴드로 설명되는 주요 피크의 비율 (특이성 확보용)
- 동점이면 밴드 위치 편차가 작은 후보를 위로 정렬
- 후보 클릭 → 검출/미검출 마커 상세

> 이건 **규칙 기반 후보 순위**입니다. 배합 grade(예: PA6 vs PA66, PPA 계열 내 개별 grade) 판정은
> 표준시료 라이브러리 대조가 필요합니다.

### 5-3. 열화 지수
프리셋(모두 밴드 **적분 면적비**, 베이스라인 두 점 명시):

- **CI — Dong 2010 (PA6, ATR 보정)**: I(1710–1760)/I(1458–1468),
  베이스라인 카르보닐 1780·1690 / 기준 1495·1435 → `재활용-pa6-carbonyl-index` 노트의 정의 그대로
- **CI_ketone** 1710–1720 / **CI_acid** 1745–1755 (산화 vs 가수분해 분리)
- **H-bond index** A(3440)/A(3300) (피크 높이비, 베이스라인 미적용)
- **CI — PE/PP 범용** A(1715)/A(2020) 관례
- **OI — 고무** 카르보닐(1700–1740)/CH₂ scissor(1440–1475)

**ATR 보정 유무 값을 함께 표시**합니다. 보정 시 CI가 약 1/1.17로 낮아지므로(침투깊이 dp ∝ 1/ν)
문헌값과 비교하려면 보정 여부를 반드시 맞춰야 합니다. 분자 면적이 0 이하이면 `n.d.`로 표시합니다
(해당 밴드 미검출 — 수치 해석 불가).

### 5-4. 차이 스펙트럼 (노화 전후 · 정상품 vs 문제품)
A − B 계산. 기준 밴드 면적(기본 1440–1480)으로 각 스펙트럼을 정규화한 뒤 빼므로,
시편 접촉·두께 차이를 상쇄한 **순수 스펙트럼 변화**를 볼 수 있습니다. 양(+)은 적색, 음(−)은 청색.
차이 스펙트럼도 피크 검출·귀속이 됩니다.

> 차이 스펙트럼은 시료별 높이 정규화가 켜져 있으면 밴드 높이에 맞춰 확대됩니다.
> 그래서 **이름에 실제 최대 진폭(Δmax)을 함께 표시**합니다 — 다른 run의 차이 스펙트럼과
> 크기를 비교할 때는 이 값을 기준으로 하세요.

### 5-5. 라이브러리 (자체 표준시료)
측정한 표준품을 등록하면 현재 전처리로 다시 처리해 **상관계수(R, R′) + 점수(0–1000)** 로 대조합니다.
`JSON 내보내기`로 백업·공유, `JSON 가져오기`로 병합. (브라우저 저장소에 보관 — PC/브라우저를 바꾸면 JSON으로 옮기세요)

## 6. 내보내기 — 학술지용 / PPT용 (v1.3)

표시 설정 → **PNG 포맷**에서 두 가지 완성 포맷과 "화면 그대로"를 고릅니다. 기본값은 **학술지(double 180 mm, 300 dpi)** 입니다.

### 6-1. 학술지 포맷

| 항목 | 값 |
|---|---|
| 크기 | double **180 mm**, single **88 mm** (해상도 300/600 dpi 선택) |
| 픽셀 | 180 mm @300 dpi = **2126×1106**, @600 dpi = 4252×2212 · 88 mm @300 dpi = 1039×686 |
| 글자 | **7 pt 고정** — 300 dpi에서 29 px. 인쇄했을 때 축 눈금이 7 pt로 나옵니다 |
| 서체 | Times New Roman 계열(serif) |
| 배경·축 | 흰 배경, 검정 축, **격자 없음**, L자 축(상·우 프레임 없음) |
| 범례 | 쓰지 않음 — 각 스펙트럼 위에 이름(잘림은 폭 기준으로 자동 처리) |
| 피크 라벨 | 시료당 **5개**(prominence 상위), 아직 검출 안 한 시료도 자동 검출 |
| 선 | 최소 **2.2 px(≈0.53 pt)** 로 보정, 투명도 100 % |
| 제외 | 선택 음영·크로스헤어 등 화면 전용 요소 |

DSC 탭의 저널 포맷은 세로가 긴 곡선이라 높이를 따로 계산하고(180 mm → 2126×893), 지면에서 글자가 겹치는 **Tg·on/end 보조 라벨은 빼고 피크 온도만** 남깁니다.

### 6-2. PPT 포맷

- **1600×900 px (16:9)**, **투명 배경**, 산세리프, 글자 26 px(슬라이드에서 ≈19 pt)
- 굵은 선(최소 3.6 px ≈ 2 pt), 피크 라벨 8개까지, 시료 **이름표 + 범례**(위치·표시는 선택)
- **잉크는 슬라이드 기준 검정** — 축선·눈금·축 제목 `#111111`, 축선 2.0 px, 내부 격자 `rgba(0,0,0,0.28)` 1.6 px(흰 배경에서 `#b8b8b8`)
- **테두리 선택** — 표시 설정의 「PPT 테두리 (사방 박스)」를 켜면 플롯 영역을 검정 1.8 px로 닫아 그립니다(기본 OFF = L자 축 + 내부 격자)
- **Y축 제목** — 스택(정규화) 모드에서도 왼쪽에 회전해 그립니다. 왼쪽 여백은 제목+눈금 숫자 폭(`fs*6`)만큼 자동 확보
- 투명 PNG를 슬라이드에 그대로 붙이면 배경색과 무관하게 읽힙니다

### 6-3. 서체 선택 — 현대하모니 (사내 서체)

표시 설정 → **내보내기 서체**. 포맷(학술지/PPT)과 별개로 글꼴만 바꿉니다.

- **포맷 기본** — PPT: Segoe UI/맑은 고딕, 학술지: Times New Roman (기본값 그대로)
- **현대하모니 L / M / B — 한글만 (권장)** — 라틴·숫자·기호는 포맷 기본 서체, **한글만** 사내 서체.
  스택은 `"Segoe UI","HDharmony L",system-ui,sans-serif` / 저널은 `"Times New Roman",…,"HDharmony L",Georgia,serif`.
  사내 서체를 제네릭 계열 **앞**에 두어 한글만 사내 서체로 가고, 라틴·숫자·기호는 원래 서체를 유지한다(실측: 저널 라틴 폭 280.84 px 불변, 한글 120 → 104.64 px).
- **현대하모니 L / M / B — 전체** — 라틴·숫자·한글 모두 사내 서체.
  ⚠ **축 제목이 벌어져 보이는 원인**: HDharmony는 `°`(0.87 em)·`¹`(0.87 em)을 **전각**으로, `µ`·`⁻`·`≈`는 **아예 없음**을 갖습니다(측정: ° 34.9 px vs Segoe 16.0 px). 그래서 `Temperature (°C)` 가 `(° C)` 처럼, `cm⁻¹` 이 들떠 보입니다. 축 제목·숫자까지 사내 서체로 통일해야 하는 경우가 아니면 **한글만**을 쓰십시오.
- **맑은 고딕** — 맑은 고딕은 `⁻`·`≈` 가 없어 `cm⁻¹` 은 Segoe/Times로 폴백됩니다.

동작 방식과 주의:

- 사내 서체 파일은 `fonts/` 폴더에 둡니다(`HDharmony-L.ttf`, `-M.ttf`, `-B.ttf`). 앱이 시작할 때 `@font-face`로 읽고, 내보내기 직전에 `document.fonts.load()`로 **로드 완료를 기다린 뒤** 그립니다(동기 렌더라 로드 전에 그리면 대체 서체로 굳음).
- **`fonts/` 폴더가 없으면 조용히 대체 서체**로 저장되고, 화면 로그에 `서체 "HDharmony L" 를 불러오지 못했습니다` 경고가 남습니다.
- 이 PC의 현대하모니 TTF는 *사용자 글꼴 폴더에 파일만 있고 Windows에 등록되지 않은 상태*라 브라우저가 이름으로 인식하지 못합니다(실측: `measureText` 폭이 미지정 서체와 동일). 그래서 설치에 의존하지 않고 **파일을 직접 읽는 방식**을 썼습니다. 정식 설치하면 `fonts/` 없이도 이름으로 동작합니다.
- 라이선스: 사내 CI 서체이므로 **공개 저장소(GitHub Pages)에는 포함하지 않았습니다**. 웹 버전은 대체 서체로 저장되고, 로컬 zip/폴더 사용 시에만 적용됩니다.
- PNG로 내보내면 글자가 픽셀로 굳으므로, **받는 사람 PC에 서체가 없어도 그림은 그대로** 유지됩니다(폰트 임베드 불필요).

### 6-4. 화면 그대로

보이는 그대로 2배 해상도로 저장하고, 배경만 **투명(기본) / 흰색 / 앱 테마** 중에서 고릅니다.
투명은 알파 채널을 유지하므로 다른 그림 위에 겹쳐 쓰거나 제출용 도판 조합에 쓸 수 있습니다.

### 6-5. 파일 형식

- **PNG**: 위 3가지 포맷
- **CSV**: 피크 표 / 정성 판정 / 지수 (Excel에서 바로 열림, UTF-8 BOM)
- **프로젝트 JSON**: 시료 원본 + 표시/전처리 설정 + 피크 라벨까지 저장·복원

## 7. DSC 탭 (v1.3)

상단 **DSC** 탭으로 전환하면 별도 화면이 열립니다. FT-IR과 같은 조작(스택, 줌, 범례 클릭, 스타일 편집, PNG/CSV 내보내기)을 씁니다.

### 7-1. 데이터

- **ASCII 텍스트** `.txt .csv .tsv .asc .dat` — `온도 / 열유량` **2~5열**. 탭·쉼표·세미콜론·공백 구분 자동, **소수점 쉼표(유럽식)** 자동 인식, 헤더·주석 줄 무시.
- 온도 열·열유량 열은 자동 판정합니다(시간축·온도축은 직선, 열유량은 요철이 있다는 성질 이용). 로그에 `온도열 N / 열유량열 M`이 찍히고, 틀리면 **분석 설정 → 온도 열 / 열유량 열 → 열 다시 읽기**로 바로잡습니다.
- Bruker 장비는 **OPUS에서 ASCII로 내보낸 뒤** 끌어다 놓으십시오(현재 OPUS DSC 바이너리는 지원하지 않습니다).
- **Netzsch Proteus `.ngb-sdf`(텍스트 export) 직접 지원** — 파일 선택 창은 확장자를 제한하지 않습니다. 형식 확인:
  ```
  #INSTRUMENT:NETZSCH DSC300 Select
  #SAMPLE MASS /mg:6.66
  #EXO:-1
  #SEG. 2:50°C/20.0(K/min)/350°C
  ##Temp./°C;Time/min;DSC/(mW/mg);Sensitaet/(uV/mW);Segment
  130.04441; 5.00083;   0.45406;3.58041;2
  ```
  `#…` 헤더는 주석으로 무시하고, `##` 다음의 데이터 5열에서 **온도(0)·열유량(2)** 를 자동 선택(시간·감도·세그먼트 열 제외). 헤더에서 **질량 `#SAMPLE MASS /mg`, 승온속도 `#SEG.`/`#RANGE`, 발열방향 `#EXO`** 를 읽어 분석 설정에 자동 적용하고 로그에 `헤더: … 질량 6.66 mg · 승온 20 K/min · EXO -1 (발열 아래)` 로 남깁니다. 실측 검증: 601점 · 50–350 °C · 단위 mW/mg · peak 220.0 °C · ΔH 38.3 J/g.

### 7-2. 분석

| 항목 | 방법 | 입력 |
|---|---|---|
| ΔH (J/g) | 적분구간에서 베이스라인 위 면적 ÷ 가열속도 (`ΔH = ∫HF dT / (β/60)`) | 가열속도, (절대단위면) 시료 질량 |
| onset / endset | 상승·하강부 **최대 기울기 접선 ∩ 베이스라인** | — |
| Tg (시작/중간/끝) | ISO 11357-2 방식: 전이 전·후 베이스라인과 **변곡 접선**의 교점, 중간값은 스텝 **반높이** | — |
| ΔCp | 스텝 높이 ÷ 가열속도 | — |
| 결정화도 | `ΔHm / ΔHm° × 100` | ΔHm°(재료 선택 또는 직접 입력) |

- **구간 자동** (기본 켜짐) — 시료마다 피크와 Tg 구간을 자동으로 잡습니다. 피크는 *피크 밖 영역으로 적합한 직선 베이스라인*을 기준으로 잡으므로 좁은 융해 피크와 넓은 경화 발열 모두 ΔH가 보존됩니다. 끄면 구간을 직접 지정합니다.
- **ΔHm°는 관용값**입니다(PE 293, PP 207, PA6 190, PBT 140, PET 140, PPS 150, PEEK 130, PLA 93 J/g). 문헌·grade에 따라 10 % 이상 차이가 나므로 **반드시 확인 후 수정**하십시오. `해당 없음`을 고르면 결정화도를 계산하지 않습니다(열경화성·비결정성).
- 100 % 결정 열량을 모르는 재료는 ΔH만 비교하십시오(노화 전후·정상품/문제품 비교에는 ΔH와 Tg 변화만으로도 충분한 경우가 많습니다).

### 7-3. 권장 흐름

1. 시료를 한 화면에 모아 **스택**으로 놓고 Tg·피크 위치가 눈에 띄는지 확인
2. 가열속도·단위·질량을 확인하고 **전체 분석**
3. **분석 결과** 표에서 Tg 중간값·ΔH·결정화도를 비교(노화 전후, 정상품/문제품)
4. 차이가 큰 시료는 구간 자동을 끄고 구간을 좁혀 재계산 → 로그에 구간·피크·ΔH가 남습니다
5. **CSV 저장**(결과 표) / **PNG 내보내기**(배경 투명)

### 7-4. 한계

- 베이스라인은 **직선 1개**입니다. Cp 변화가 큰 시료, 열량 보정 전 데이터, 곡선 베이스라인이 필요한 경우 결과가 달라집니다 → 계측기 소프트웨어에서 베이스라인을 만든 뒤 내보내십시오.
- 1차 스캔의 **열이력(quench·annealing)** 은 ΔH·Tg에 그대로 반영됩니다. 비교는 **같은 열이력**의 시료끼리 하십시오.
- 전압 단위(µV/mV) 데이터는 보정계수가 없으면 ΔH를 계산하지 않습니다(단위를 mW/mg로 바꾸거나 질량을 입력).
- 산화유도시간(OIT), 변조 DSC(역상 Cp), 다중 승온 분리(peak deconvolution)는 지원하지 않습니다.

## 8. TGA 탭 (v1.4)

상단 **TGA** 탭. FT-IR·DSC와 같은 조작(겹쳐보기/스택, 줌, 스타일, PNG·CSV, 프로젝트 저장)을 씁니다.

### 8-1. 데이터

- **ASCII** `.txt .csv .tsv .asc .dat` — `온도 / 중량(%)` **2~5열**(탭·쉼표·세미콜론·공백). 헤더·주석 무시, 소수점 쉼표 인식.
- 열 자동 판정: **온도 열** = 단조 증가(0에서 시작하면 시간축으로 감점), **중량 열** = 초기 ≈100 %에서 전체적으로 감소. 시간·온도·중량 3열이면 시간 열을 자동 제외. 로그에 `온도열 N / 중량열 M (열 수, 구분자)`가 찍히고, 틀리면 **분석 설정 → 온도 열 / 중량 열**을 직접 지정하고 파일을 다시 불러옵니다.

### 8-2. 계산

| 항목 | 방법 |
|---|---|
| T5% · T10% · T50% | 초기 수평부 평균을 100 %로 잡고, 규정 감량에 **도달하는 온도**(선형 보간) |
| Td,onset | 최대 기울기 구간(최대 |dW/dT| 의 30 % 이상)에 직선 적합 → **초기 수평선과의 교점** |
| Tmax | DTG(−dW/dT) 최대점의 온도 |
| 잔량 (residue) | 마지막 **2 % 구간 평균** 중량 |
| 중량 감소 단계 | 평탄 구간(|dW/dT| < 문턱) 사이의 손실량·구간 |

- **스무딩**(점 수)은 표시와 분석에 함께 적용합니다(기본 5점).
- **정규화**: 절대 mg 데이터도 초기 수평부를 100 %로 다시 맞춰 계산합니다(원본 y축은 보존).

### 8-3. 우측 요약 패널

- 기본 켜짐. 오른쪽에 **T5% / Td onset / 최종 잔량** 세 개의 작은 산점도를 세로로 붙입니다 — 첨부 슬라이드의 "T5% and final residue" 구성과 같습니다.
- 값 라벨은 자동: 칸 폭이 좁으면 단위를 뺀 숫자만, 그래도 안 들어가면 생략(표에 모두 있음).
- 시료 코드는 **요약 패널 시료 코드**에 `AB, BB`처럼 쉼표로 넣어 바꿉니다(비우면 이름, 이름이 길면 S1…Sn).
- 저널 포맷은 기본적으로 범례를 숨기지만, TGA **겹쳐보기**에서는 시료 구분을 위해 작은 범례를 넣습니다.

### 8-4. 한계

- 승온속도를 결과에 쓰지 않으므로 **kinetics(Ea, 반응차수) 계산은 하지 않습니다**(T5%·Td·잔량 비교용).
- TGA는 **분위기(air/N₂)와 유량**에 민감합니다. 산화 분해는 공기 중에서 온도가 크게 낮아지므로, 비교는 **같은 분위기**에서 측정한 데이터끼리만 하십시오.
- 충전제(유리섬유·탈크·CaCO₃) 잔량은 **회분(ash)** 과 같지 않습니다. CaCO₃는 분해되고 탈크는 남는 등 조성에 따라 다릅니다.
- 보정(온도·중량 보정) 이력이 다른 데이터는 onset이 수 °C 이동할 수 있습니다.

## 9. 한계와 주의

- **충전제 간섭**: 유리섬유(Si–O 1000–1100 광범위), 탈크(3676, 1018), CaCO₃(1420, 872), 카본블랙(전 구간 흡수)
  은 수지 밴드를 가립니다. 해당 대역이 넓게 올라와 있으면 충전제를 먼저 의심하세요.
- **PA6 vs PA66**: 스펙트럼이 매우 유사합니다. FTIR 단독 판정 대신 DSC 용융피크·용해도·공급 이력으로 교차 확인하세요.
- **ATR 보정은 단순형**입니다. 파수 의존 굴절률 분산을 반영한 상용 보정(OPUS Advanced ATR)과는 차이가 있을 수 있습니다.
  상용 보정값과 섞어 쓰지 마세요.
- **정량 아님**: 정성 판정 점수는 확률이 아닙니다. 지수(CI 등)도 상대 비교용이며 절대값의 물리적 의미는
  베이스라인·접촉압·결정 조건에 좌우됩니다.
- **밴드 위치**는 문헌 대표값(범위)입니다. 실제 시료는 결정형·수소결합·배합에 따라 이동합니다.
- `samples/*.dpt` 는 **합성 데모 데이터**입니다(실측값 아님) — 조작 방식 확인용으로만 쓰세요.

## 10. .exe로 배포하고 싶다면

현재 형태(HTML 한 파일 + bat)는 설치·관리자권한·백신 오탐 이슈가 없어 사내 배포에 가장 안전합니다.
굳이 단일 실행 파일이 필요하면:

- **pywebview**: `pip install pywebview` 후 HTML을 띄우는 20줄 파이썬 → PyInstaller `--onefile` (~15 MB)
- **Tauri**(Rust) 또는 **Neutralino**: 웹 자산을 그대로 감싸는 경량 실행 파일
- 사내 보안 정책상 exe 반입이 어려우면 지금 방식(bat + html)이 정답입니다.
