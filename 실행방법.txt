FTIR Studio v1.4 — 웹에서 바로 쓰기
====================================

[가장 빠른 방법]
  https://seongsoonhwang.github.io/ftir-studio/ 를 브라우저로 엽니다.
  → 설치 없이 그대로 실행됩니다. 데이터는 브라우저 안에서만 처리되고 외부로 전송되지 않습니다.

[화면 구성 — 상단 탭]
  · FT-IR : OPUS 원시 파일(.0/.1)과 ASCII(.dpt) 스펙트럼 — 정성 판정·열화 지수·차이 스펙트럼
  · DSC   : DSC ASCII(온도/열유량) — ΔH·onset/endset·Tg·ΔCp·결정화도  (v1.3 추가)
  · TGA   : TGA ASCII(온도/중량) — T5%·T10%·T50%, Td onset, Tmax, 잔량, 감소 단계  (v1.4 추가)

[v1.4에서 추가된 것]
  · 우측 요약 패널 (DSC·TGA 공통) — 메인 곡선 오른쪽에 주요 지점만 따로 그린 작은 그래프
      - DSC : 전이 온도(Tm●/Tc◆/Tg■) 패널 + ΔH 패널
      - TGA : T5% 패널 + Td onset 패널 + 최종 잔량 패널
    → 표시 설정에서 끌 수 있고, PNG(학술지/PPT) 내보내기에도 함께 그려집니다
       (첨부하신 DSC·TGA 슬라이드처럼 "왼쪽 곡선 + 오른쪽 요약" 한 장 구성)
  · TGA 분석 탭 — T5%·T10%·T50%(규정 감량 도달 온도), 외삽 분해개시온도 Td,onset,
    DTG 최대점 Tmax, 최종 잔량, 중량 감소 단계 표, 결과 CSV·PNG
  · 열 자동 판정 — 시간·온도·중량 3열이면 시간 열을 자동으로 제외(틀리면 열 번호 직접 지정)
  · 요약 패널 시료 코드 입력(예: AB, BB) — 슬라이드에서 쓰는 시료 명칭 그대로 표시
  · 내보내기 서체 선택 (표시 설정 → 내보내기 서체)
      - 현대하모니 L·M·B 「전체 적용」 : 라틴·숫자·한글 모두 사내 서체 (PPT 슬라이드 권장)
      - 현대하모니 L·M·B 「한글만」   : 라틴·숫자는 포맷 기본, 한글만 사내 서체 (저널 도판용)
    → fonts/ 폴더의 TTF(HDharmony-L.ttf 등)를 직접 읽으므로 글꼴 설치가 필요 없습니다.
      fonts/ 폴더가 없으면 조용히 대체 서체로 저장되고 로그에 경고가 남습니다.
      (사내 CI 서체라 공개 저장소에는 넣지 않았습니다 — 웹 버전은 대체 서체로 나옵니다.
       PNG는 글자가 픽셀로 굳으므로 받는 분 PC에 서체가 없어도 그림은 그대로입니다.)

[v1.3에서 추가된 것]
  · DSC 분석 탭 — 피크 적분(ΔH, J/g), 외삽 onset/endset, Tg(시작/중간/끝)+ΔCp,
    결정화도(ΔHm/ΔHm°), 구간 자동 검출, 결과 CSV·PNG 내보내기
  · 그림 포맷 선택 (표시 설정 → PNG 포맷)
      - 학술지(기본) : double 180 mm / single 88 mm · 300·600 dpi · 글자 7 pt 고정
                       흰 배경 · serif · 격자 없음 · 범례 대신 스펙트럼 위 이름 · 피크 5개
      - PPT         : 1600x900(16:9) · 투명 배경 · 굵은 선 · 이름표+범례 · 피크 8개
      - 화면 그대로 : 2배 해상도, 배경 투명/흰색/앱 테마 선택
    → 학술지 포맷은 인쇄 크기(mm)와 글자 크기(pt)를 같이 맞추므로
      파워포인트·일러스트에 그대로 넣어도 축 눈금이 7 pt로 유지됩니다

[v1.2까지]
  · 특정 밴드 피크 높이 정규화(내부 표준), 표시구간 기준 y범위 정규화
  · OPUS 원시 바이너리(.0/.1) 직접 읽기 + MNY/MXY 무결성 검사

[내 PC에 파일로 보관하려면]
  1) 위 주소를 연 뒤 Ctrl+S → "웹페이지, 완전히" 로 저장 (ftir-studio-single.html 과 동일)
  2) 또는 저장소에서 ftir-studio-single.html 을 내려받아 더블클릭
  3) 주소창 없는 앱 창으로 쓰려면 실행.bat 을 ftir-studio.html 과 같은 폴더에 두고 더블클릭
     (Edge/Chrome --app 모드, 창 크기 1500x950)

[주소창 없는 앱 창으로 쓰고 싶으면]
  Edge 로 위 주소를 연 뒤 ... → 앱 → "이 사이트를 앱으로 설치"
  → 바탕화면 아이콘으로 실행 (실행.bat 과 동일한 효과)

[소스]
  같은 폴더의 app*.js, lib-bands.js, demo.js, dsc-core.js, dsc.js, tga-core.js, tga.js, app.css 가 모듈 버전 소스입니다.
  tools/bundle.py 로 모듈을 다시 단일 파일로 묶을 수 있고,
  tools/gen_samples.js (FT-IR), tools/gen_dsc_samples.js (DSC), tools/gen_tga_samples.js (TGA)
  로 합성 데모를 재생성할 수 있습니다.
  TGA 탭 소스는 tga-core.js(엔진) + tga.js(UI) 입니다.
