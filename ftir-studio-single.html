        FT-IR Studio — 사용 안내

        1. 데이터 불러오기

        1. OPUS 원시 바이너리(.0, .1 …)를 그대로 끌어다 놓으면 됩니다. 별도 변환 없이 읽습니다.
        2. 파일 안에 인터페로그램·단일채널·흡광도가 함께 들어 있으면 흡광도(결과 스펙트럼)를 자동 선택합니다. 무엇을 선택했는지 로그에 표시됩니다.
        3. 읽은 뒤 파일 내부의 MNY/MXY(저장된 최소·최대값)와 실제 계산값을 대조합니다. 불일치하면 값을 신뢰할 수 없으므로 불러오지 않고 로그에 실패로 남깁니다.
        4. ASCII(.dpt .txt .csv, 2열) 파일도 그대로 지원합니다 — 둘 중 편한 쪽을 쓰세요.
        5. 지원하지 않는 것: 3D 시계열(series) 블록, 라이브러리 검색·정량 리포트 블록, OPUS가 아닌 다른 제조사 포맷.

        2. 화면 조작

        • 드래그: X 구간 확대 · 휠: 확대/축소 · 더블클릭: 초기화
        • 범례 클릭 → 해당 시료 선택 (왼쪽에서 색·굵기·선형태·범례 문구 수정)
        • 스택 모드에서 시료 순서는 왼쪽 목록의 ↑↓로 바꿉니다.

        3. 그림 내보내기 — 학술지용 / PPT용

        • 표시 설정 → PNG 포맷에서 고릅니다. 기본값은 학술지 (double 180 mm, 300 dpi)입니다.
        • 학술지: 흰 배경 · Times 계열 · 격자 없음 · 범례 대신 스펙트럼 위 이름 · 피크 라벨은 시료당 5개 · 최소 선굵기 0.53 pt. 폭(single 88 mm / double 180 mm)과 해상도(300/600 dpi)를 지정하며, 글자는 항상 7 pt로 계산되므로 인쇄했을 때 눈금이 7 pt로 나옵니다.
        • PPT: 1600×900(16:9) · 투명 배경 · 굵은 선(≈2 pt) · 큰 글씨 · 검정 축 + 내부 격자(축·테두리 #111111 2.4 px, 격자 rgba(0,0,0,0.45) 2.0 px) · 이름표+범례 · 피크 라벨 8개까지.
        • 화면 그대로: 보이는 그대로 2배 해상도. 배경은 투명/흰색/앱 테마 중 선택.
        • 내보내기에는 화면 전용 요소(선택 음영·크로스헤어)가 빠지고, 피크를 아직 검출하지 않은 시료도 자동으로 검출해 라벨을 붙입니다.
        • 범례: 「범례 표시」로 켜고 끄며, 위치는 바깥 위·아래·왼쪽·오른쪽과 안쪽 네 모서리 중에서 고릅니다. 위·아래는 가로로 늘어놓고 폭이 모자라면 자동으로 다음 줄로 넘기며, 플롯 여백을 그만큼 확보합니다. 바깥 오른쪽은 요약 패널이 켜져 있으면 안쪽 오른쪽 위로 물러납니다. 학술지 포맷은 그림 안 시료명을 쓰므로 범례를 그리지 않습니다.
        • 축 제목: X축 제목은 아래 가운데, Y축 제목은 왼쪽에 세로로 그립니다. 스택(시료별 높이 정규화) 화면에서도 표시되며, 왼쪽 여백은 제목 폭만큼 자동으로 늘어납니다.
        • PPT 테두리: PPT 포맷에서 플롯 영역을 사방 검정 박스로 닫습니다(기본 OFF = 왼쪽·아래 축 + 내부 격자).
        • 내보내기 서체: 포맷과 별개로 글꼴만 바꿉니다. 현대하모니 L·M·B는 한글만(권장)과 전체 중에서 고릅니다. 한글만은 라틴·숫자·기호를 포맷 기본 서체(Segoe UI / Times)로 두고 한글만 사내 서체로 씁니다. 전체로 두면 축 제목의 °·¹ 이 전각으로, µ·⁻·≈ 은 사내 서체에 없어 폴백되므로 Temperature (°C) 가 (° C) 처럼 벌어져 보입니다 — 축 제목 가독성이 중요하면 한글만을 쓰십시오. 사내 서체는 fonts/ 폴더의 TTF를 직접 읽으므로 설치가 필요 없고, 폴더가 없으면 조용히 대체 서체로 저장되며 로그에 경고가 남습니다. 공개 웹 버전에는 서체 파일이 없어 대체 서체로 나옵니다(PNG는 글자가 픽셀로 굳으므로 받는 사람 PC에 서체가 없어도 동일).

        4. 분석 흐름 권장

        1. 전처리: 스무딩 → 베이스라인(러버밴드 권장) → (ATR이면) ATR 보정 → 정규화
        2. 내부 표준 정규화: 정규화에서 “특정 밴드 피크 높이”를 고르고 기준 밴드(예: PA6 1440–1480)를 지정하면 그 피크가 1.0이 됩니다. 시편 두께·접촉 압력이 달라도 상대 강도를 비교할 수 있습니다.
        3. 피크 표: 검출 후 귀속 후보 확인, 필요 없으면 라벨 편집
        4. 정성 판정: 마커 밴드 점수로 후보 순위 → 상위 후보를 라이브러리 상관으로 재확인
        5. 열화 지수: CI(Dong 2010) 등 프리셋으로 정량 비교, ATR 보정 유무 값 병기
        6. 비교: A−B 차이 스펙트럼으로 노화/공정 문제 밴드 특정

        5. 한계

        • 마커 점수는 규칙 기반입니다. 실제 배합 grade 판정에는 표준시료 라이브러리가 필요합니다.
        • 충전제(GF·탈크·CaCO₃·카본블랙)는 수지 밴드를 가립니다. 1000–1100 cm⁻¹ 광범위 흡수는 GF 가능성을 먼저 의심하세요.
        • ATR 보정은 단순형(A·ν/1000)입니다. 정밀 정량에는 파수 의존 n 분산을 반영한 상용 보정과 차이가 있을 수 있습니다.
        • OPUS 바이너리 리더는 공개 포맷 문서와 오픈소스 구현(brukeropus·openreadout)을 근거로 작성했습니다. 사내 OPUS 버전·3D 파일처럼 검증하지 못한 변형이 있으면 로그에 실패로 표시됩니다.

        6. DSC 탭 (v1.3 추가)

        1. 계측기 원본 텍스트 export 도 그대로 됩니다 — Netzsch Proteus .ngb-sdf(헤더 #… + Temp./°C;Time/min;DSC/(mW/mg);… 5열) 형식을 확인했습니다. 이때 #SAMPLE MASS /mg(질량) · #SEG.·#RANGE(승온속도) · #EXO(발열 방향) 를 자동 적용하고 로그에 표시합니다. 파일 선택 창은 확장자를 제한하지 않습니다.
        2. 상단 DSC 탭으로 전환 → 왼쪽에 DSC 파일을 끌어다 놓습니다. 온도 / 열유량 2~5열 ASCII(.txt .csv .tsv)를 읽습니다 — 탭·쉼표·세미콜론·공백 구분, 소수점 쉼표 형식도 자동 인식합니다.
        3. 분석 설정에서 시료 질량(mg)·가열속도(°C/min)·열유량 단위를 확인합니다. 단위가 mW/mg·W/g면 ΔH가 바로 나오고, mW(절대값)면 질량으로 나눠 환산합니다.
        4. 피크 구간(예: PA6 융해 180–250 °C)을 지정하면 그 구간 양끝을 잇는 직선 베이스라인으로 ΔH(J/g), peak, 외삽 onset/endset을 계산합니다.
        5. Tg 구간을 지정하면 스텝의 onset / 중간(반높이) / end 와 ΔCp를 계산합니다(ISO 11357-2 방식의 외삽 접선).
        6. 결정화도는 ΔHm ÷ ΔHm° × 100 입니다. ΔHm°는 재료를 고르면 관용값이 채워지지만 문헌·grade별로 10 % 이상 차이가 나므로 반드시 확인 후 수정하십시오.
        7. PNG 내보내기는 FT-IR 탭과 같이 포맷(학술지 / PPT / 화면 그대로)을 고를 수 있습니다. 저널 포맷은 DSC 세로 비율에 맞춰 높이를 따로 계산하고, Tg·on/end 보조 라벨은 빼고 피크 온도만 남깁니다(지면에서 글자가 겹치기 때문).
        8. 우측 요약 패널 (v1.4): 메인 곡선 오른쪽에 전이 온도(Tm·Tc·Tg)와 ΔH만 따로 그린 작은 그래프가 붙습니다. 시료 간 비교용이며, 시료가 많거나 폭이 좁아 글자가 안 들어가면 값 라벨은 자동으로 생략됩니다(표에 그대로 있음). 표시 설정에서 끌 수 있습니다.
        9. 한계: 기준선이 곡선인 경우(열량 보정 전, Cp 변화가 큰 시료) 결과가 달라질 수 있습니다. 필요하면 OPUS/계측기 소프트웨어에서 베이스라인을 만든 뒤 다시 내보내세요.

        7. TGA 탭 (v1.4 추가)

        1. 상단 TGA 탭 → 왼쪽으로 TGA ASCII(.txt .csv .tsv)를 끌어다 놓습니다. 온도 / 중량(%) 2~5열을 읽고, 시간 열이 함께 있으면 자동으로 제외합니다.
        2. 자동 계산: T5%·T10%·T50%(초기 수평부 대비 규정 감량에 도달하는 온도, 선형 보간), Td,onset(최대 기울기 구간 접선과 초기 수평선의 교점), Tmax(DTG 최대점), 잔량(마지막 2 % 평균), 중량 감소 단계(평탄 구간 사이 손실).
        3. 겹쳐보기는 중량 % 축 하나에 모두 그리고, 스택은 시료별로 띄워 그립니다. 스무딩(점 수)은 표시와 분석에 같이 적용됩니다.
        4. 우측 요약 패널이 기본으로 켜져 있어 T5% · Td onset · 최종 잔량을 시료별 점으로 따로 보여 줍니다(첨부하신 DSC/TGA 슬라이드 형식). 시료 코드는 "요약 패널 시료 코드"에 쉼표로 넣어 바꿀 수 있습니다(예: AB, BB).
        5. 열 판정이 틀리면 온도 열·중량 열 번호를 직접 넣고 파일을 다시 불러오세요. 로그에 선택된 열과 구분자가 표시됩니다.
        6. 한계: 중량 %가 100 기준으로 정규화되지 않은 파일(절대 mg)은 초기 수평부를 100 %로 다시 맞춰 계산합니다. 승온속도는 결과에 들어가지 않으므로 kinetics(Ea) 계산은 하지 않습니다.
