    FT-IR Studio — 사용 안내

    1. 데이터 불러오기

    1. OPUS 원시 바이너리(.0, .1 …)를 그대로 끌어다 놓으면 됩니다. 별도 변환 없이 읽습니다.
    2. 파일 안에 인터페로그램·단일채널·흡광도가 함께 들어 있으면 흡광도(결과 스펙트럼)를 자동 선택합니다. 무엇을 선택했는지 로그에 표시됩니다.
    3. 읽은 뒤 파일 내부의 MNY/MXY(저장된 최소·최대값)와 실제 계산값을 대조합니다. 불일치하면 값을 신뢰할 수 없으므로 불러오지 않고 로그에 실패로 남깁니다.
    4. ASCII(.dpt .txt .csv, 2열) 파일도 그대로 지원합니다 — 둘 중 편한 쪽을 쓰세요.
    5. 지원하지 않는 것: 3D 시계열(series) 블록, 라이브러리 검색·정량 리포트 블록, OPUS가 아닌 다른 제조사 포맷.

    2. 화면 조작

    • 드래그: X 구간 확대 · 휠: 확대/축소 · 더블클릭: 초기화
    • 범례 클릭 → 해당 시료 선택 (왼쪽에서 색·굵기·선형태·범례 문구 수정)
    • 스택 모드에서 시료 순서는 왼쪽 목록의 ↑↓로 바꿉니다.

    3. 분석 흐름 권장

    1. 전처리: 스무딩 → 베이스라인(러버밴드 권장) → (ATR이면) ATR 보정 → 정규화
    2. 내부 표준 정규화: 정규화에서 “특정 밴드 피크 높이”를 고르고 기준 밴드(예: PA6 1440–1480)를 지정하면 그 피크가 1.0이 됩니다. 시편 두께·접촉 압력이 달라도 상대 강도를 비교할 수 있습니다.
    3. 피크 표: 검출 후 귀속 후보 확인, 필요 없으면 라벨 편집
    4. 정성 판정: 마커 밴드 점수로 후보 순위 → 상위 후보를 라이브러리 상관으로 재확인
    5. 열화 지수: CI(Dong 2010) 등 프리셋으로 정량 비교, ATR 보정 유무 값 병기
    6. 비교: A−B 차이 스펙트럼으로 노화/공정 문제 밴드 특정

    4. 한계

    • 마커 점수는 규칙 기반입니다. 실제 배합 grade 판정에는 표준시료 라이브러리가 필요합니다.
    • 충전제(GF·탈크·CaCO₃·카본블랙)는 수지 밴드를 가립니다. 1000–1100 cm⁻¹ 광범위 흡수는 GF 가능성을 먼저 의심하세요.
    • ATR 보정은 단순형(A·ν/1000)입니다. 정밀 정량에는 파수 의존 n 분산을 반영한 상용 보정과 차이가 있을 수 있습니다.
    • OPUS 바이너리 리더는 공개 포맷 문서와 오픈소스 구현(brukeropus·openreadout)을 근거로 작성했습니다. 사내 OPUS 버전·3D 파일처럼 검증하지 못한 변형이 있으면 로그에 실패로 표시됩니다.
